## 5. File-level audit (the 4 in-scope repos) — method

Run inside `heady-ai` (`rebuild`) — these are the existing, runnable gates;
nothing here deletes, it *reports*:
```bash
pnpm install --frozen-lockfile          # required: the gates need the workspace
node tooling/coherence/src/coherence.mjs all      # contradictions / two-sources-of-truth
pnpm run scan:stale                                # stale files
pnpm exec knip                                     # orphan exports/files (dead code)
pnpm exec depcruise --validate                     # orphan modules

```
Outputs become the authoritative **keep/eliminate** list for files in the
canonical repo. `knip ∩ dependency-cruiser` = orphan; coherence contradictions =
duplicate-source-of-truth to collapse.
